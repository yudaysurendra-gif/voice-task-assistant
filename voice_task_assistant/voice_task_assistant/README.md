# Voice Task Assistant

A simple voice-controlled to-do list manager built with Python.

## Setup
    pip install -r requirements.txt
    python voice_task_assistant.py

## Voice Commands
- "add task buy groceries"
- "show tasks"
- "complete task 1"
- "delete task 2"
- "clear all tasks"
- "help"
- "exit"

Tasks are saved in tasks.json. If no microphone is available, type the commands instead.
